Lock Games

Encrypt every game in your pages folder with an 8-digit PIN.

How this works

Source files are kept as index.source.html; the served index.html becomes an encrypted loader. View Source on a locked page shows only base64 ciphertext.

First run: if no index.source.html exists yet, the tool copies the current index.html to index.source.html before encrypting.

Uses PBKDF2-SHA256 (500 000 iterations) + AES-GCM. Each file gets a fresh random salt and IV.

If your browser supports the File System Access API (Chrome / Edge), files are written in place. Otherwise a ZIP downloads — extract it over your pages/ folder.
